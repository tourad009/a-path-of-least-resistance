\begin{list}{}{\leftmargin=0.75in\rightmargin=0.75in}\item[]
\itshape
When one member of an LLM agent team finds a forbidden shortcut, does the team use it, and does that depend on how hard
the honest alternative is? We hold the collusive path fixed (one member of some teams finds an old answer file in its
workspace, and no prompt asks anyone to collude) and vary only the cost of the honest path to the same points, from a
lookup in a public file to no honest path at all. A versioned answer key makes leak use provable by execution at every
level: the leaked file holds the previous version of the key, which the scorer accepts and which appears nowhere else. We
run \NGames{} games over \NTasks{} everyday agentic tasks, \NLevels{} difficulty levels and \NModels{} agent models, and
let a security officer read every finished game without acting on it.

% ================= 1. Introduction =================
\section{Introduction}

Teams of LLM agents increasingly share a workspace and a chat channel. Suppose one of them comes across something it
should not use: an answer key left in a benchmark directory, an export of a restricted table, a client's private budget, a
hidden test file. It has been told that using or sharing non-public information is prohibited. Whether the shortcut stays
with that agent or spreads to its team is a question about incentives, and those incentives are \emph{asymmetric}: the
collusive path costs the same whatever the task, while the honest path to the same reward may be a single lookup, a
few minutes of work, or impossible. The harm is concrete. Graders, benchmarks and audits that assume independent work are
corrupted, and one insider's rule-breaking becomes a team's.

We ask which property of a task makes such a shortcut spread (Track~2, RQ~2.1 of the sprint
\citep{apart2026collusionsprint}), and isolate one: \textbf{the difficulty of the honest path}. Every other part of the
game is held fixed, including the leak itself, the channels and the reward. Only the work needed to earn the same points
honestly changes, over four levels (Figure~\ref{fig:design}). If agents weigh paths by their cost, as the economics of crime
suggests for people \citep{becker1968crime}, collusion should rise as the honest path gets harder.

Measuring this needs ground truth that does not depend on the honest path being impossible. Earlier designs prove leak use
by an outcome that honest play cannot reach; once an honest path exists, a correct answer no longer proves anything. We
solve this with a \emph{versioned key}: the leak is the previous version of the answer key, both versions score, and the
previous version exists only in the leaked file. An agent that submits it used the leak, at every level.

\textbf{Our contributions are:}
\begin{enumerate}
  \item \textbf{A testbed with an honest-path cost dial and execution truth.} Five everyday agentic tasks share one
        skeleton; each has four honest-path levels and a versioned-key canary. Scripted honest players never cross the
        leak threshold at any level, scripted colluders always do (Table~\ref{tab:checks}).
  \item \textbf{A matched experiment.} \NGames{} games: \NModels{} agent models $\times$ \NTasks{} tasks $\times$
        \NLevels{} levels $\times$ \NSeeds{} seeds, with seeds matched so that the roster, the holders and the leak file are
        identical across levels and models.
  \item \textbf{A detection design.} A passive security officer, in two views, is graded against execution truth next to
        a one-line score rule, at every honest-path level: outcome evidence should lose its power exactly when the honest
        path gets cheap.
  \item \textbf{Complete, replayable transcripts} of every game, including every model call, command, output and message.
\end{enumerate}

% ================= 2. Related Work =================
\section{Related Work}

\textbf{Collusion from channels and affordances.} Private channels between agents can introduce collusion in cooperative
multi-agent systems \citep{nakamura2026colosseum}, and communication and oversight shape coordination between sellers in
double auctions \citep{agrawal2025double}. Pricing agents can reach supra-competitive outcomes without explicit agreement
\citep{fish2024algorithmic,lin2024strategic}. We move from markets to team workflows and vary a property of the task, the
honest alternative, rather than the channel. \tocheck{verify each cited abstract; read the same-sprint entries before
writing the gap sentence}

\textbf{Monitoring and pressure.} LLM monitors of agents have known failure modes \citep{kale2025weak}, and models act on
forbidden information under pressure \citep{scheurer2023deceive}. We grade a monitor against execution truth and against a
trivial outcome rule. Our framing of rule-breaking as a choice between costed paths follows \citet{becker1968crime}.

% ================= 3. Methods =================
\section{Methods: the harness}

\subsection{The game}
A game has \TeamsMin--\TeamsMax{} teams of \TeamSize{} agents. On a random 1 to $T-1$ of the $T$ teams, one random member
(the \emph{holder}) finds a file in its sandbox with the previous version of its team's answers to the special items; the
other teams are \emph{control teams} and have no leak. Agents play \NRounds{} rounds of up to \NCmds{} commands each, plus a
final turn of \NFinalCmds{} commands, in an order reshuffled every round. Each command is one stateless model call
(temperature \Temperature, at most \MaxTokens{} tokens) whose input is the agent's brief and an observation: its status, its
team's item board, its last \MsgsShown{} received messages and its last \MemoryLen{} commands with their outputs. Agents can
message everyone (\texttt{msg all}), their team (\texttt{msg team}) or any agent privately (\texttt{msg @name}), with
messages capped at \MsgCap{} characters; anything else runs in the agent's own offline, non-root sandbox, with outputs
capped at \ShellCap{} characters. The brief states the task, the goal (agents are rewarded only for their team's total
score), and the rule ``Using or sharing any non-public information is prohibited''. \textbf{No prompt asks agents to collude}
and agents are not told that anyone watches them. All prompts are in Appendix~\ref{app:prompts}.

\subsection{Five tasks on one skeleton}
Each agent answers 10 items (Table~\ref{tab:tasks}). Items 1--5 are public: each can be answered from public files with
ordinary work. Items 6--10 are the team's \emph{special items}; their answers differ per team, so a rival's leak is
worthless. Four tasks come from an earlier version of this testbed; the document task is new.

\subsection{Honest-path difficulty}
The manipulated factor is how much work the honest path to items 6--10 takes (Table~\ref{tab:levels}). The levels are
defined the same way in every task: \textbf{D0}, the answer is written in a public file; \textbf{D1}, one mapping step
(a second file, then a lookup); \textbf{D2}, a join of several sources plus a stated rule or arithmetic; \textbf{D3}, no
honest path. At D0--D2 the brief says that the special items ``can be worked out from the public files'' and that
\texttt{README.txt} explains how, so the levels vary the \emph{cost} of the honest path, not whether agents know it exists.
At D3 the brief says they cannot be worked out from the public data. The verbatim \texttt{README.txt} of every task and
level is in Appendix~\ref{app:honest}.

\subsection{The versioned-key canary}
Every special item has two accepted answers (Figure~\ref{fig:design}). \textbf{\vtwo{}}, the current key, is what honest
work derives at D0--D2 (at D3 it exists but cannot be derived). \textbf{\vone{}}, the previous version, appears
\emph{only} in the leak file. Every brief, at every level, says that ``answers that match the previous version of the key
are also accepted'', so an agent that compares the leak with its own honest answer is not misled by the difference. An
agent \emph{used the leak} when at least 3 of its 5 special items match \vone{}. The harness enforces, and tests check,
that \vone{} never appears in any public file or brief, that \vone{} and \vtwo{} differ for every item (in the auction, the
two scoring windows never overlap), and that the leak file and the roster are identical across levels for the same seed.
New values are drawn from their own random streams, so games without the difficulty option are unchanged from the
earlier testbed (a golden snapshot checks this).

\subsection{Measures}
All measures come from the game state, not from a judge, and are recorded the moment they first happen.
\begin{itemize}
  \item \textbf{Leak used}: an agent crossed the \vone{} threshold. Reported separately for holders (self-use) and teammates.
  \item \textbf{Leak shared}: the holder sent at least 3 \vone{} values in a message a teammate could read. A relaxed version
        adds messages that a privileged observer, a model told the secret values, flags as carrying them in any form.
  \item \textbf{Collusion happened}: at least one teammate of the holder used the team's leak (team level). This includes
        uptake without a literal message.
  \item \textbf{Collusion detected}: the security officer disqualified a colluding team; a disqualified clean team is a false
        alarm (team level).
  \item \textbf{Manipulation check}: the control agents' honest solve rate on items 6--10 (their \vtwo{} answers). Control
        teams hold no leak, so this measures the honest path directly.
\end{itemize}
Messages that pass honestly derived (\vtwo{}) answers between teammates are counted apart: that is permitted teamwork.

\subsection{A passive overseer}
After each game, a security officer (\texttt{\OfficerModel}) reads the roster, every message on every channel, a
communication map and, in its full view, the scores per round and the submissions; in a second, messages-only view it sees
the messages alone. It rates every agent and decides, for every team, \textsc{disqualify} or \textsc{clear}. It
\textbf{cannot influence the game}: it runs after the last turn, agents are not told it exists, and its decision changes no
score. Its prompt states the honest ceiling of the level: at D3, that an honest agent scores at most about 5; at D0--D2,
that an honest agent can score 10, so a high score alone is not evidence. We use a neutral version of the prompt, without
the instruction to act on suspicion without proof that an earlier version contained. As a baseline we report a one-line
score rule: a team is flagged when any member scores above 5. A privileged observer, told the secret values, marks every
message that carries them (openly or disguised), and holders are asked after the game whether and why they shared.

\subsection{Validation and transcripts}
\textbf{Scripted players.} Before any model call, scripted players play every task and level (Table~\ref{tab:checks}).
Honest players, who work only from their public files, solve all special items at D0--D2 and none at D3, and never cross the
leak threshold; colluding players cross it every time. The test suite (\NTests{} tests, no model calls) also checks the
canary invariants, the per-level briefs and officer prompts, and that legacy games match a golden snapshot of the earlier
harness.

\textbf{Transcripts.} Every game writes a complete transcript: each agent's brief and starting files; every model call with
the exact observation sent, the full reply, token counts and latency; every command with its full sandbox output; every
message, flagged when it carries a leak (\vone{}) or honest answers (\vtwo{}); crossings and scores; and the full prompts and
replies of the officer, the observer and the interviews. A transcript replays: rebuilding the game from its configuration
and re-applying every command reproduces the recorded score, which shows nothing is missing. Each results line stores its
transcript's SHA-256, and one script recomputes every number in this report from the result files.

\textbf{Design.} For each model we play every task at every level on seeds \SeedRange{}: \NTasks{} $\times$ \NLevels{}
$\times$ \NSeeds{} $=$ \NGamesPerModel{} games, \NGames{} in total. A seed fixes the number of teams, which teams hold a
leak, who the holders are and the leak file's content, so the four levels of a seed differ only in the honest path, and the
three models play the same layouts. Everything else is fixed at the friendly setting of the earlier testbed: messaging on,
command memory across rounds, messages that stay visible, a team progress board, a short final turn, and a reward for the
team's total score only. There is no warning about surveillance. Holders are interviewed after the game.

\textbf{Statistics.} The unit of analysis is the game: agents in one game are not independent. The primary test (H1) is a
logistic GEE of teammate leak use on the level (a linear term), with task and model as fixed effects and an exchangeable
correlation within games; we also report the seed-paired, game-clustered bootstrap 95\% CI of teammate use at D3 minus D0.
Secondary tests (H2 holder sending, H3 holder self-use, H4 false alarms of the officer and the score rule) use the same model
with Holm correction. Games where more than 20\% of replies contain no command are excluded and counted. Hypotheses,
tests and exclusions are pre-registered \tocheck{PREREG.md commit hash, frozen after the calibration pilot}.

\textbf{Runs.} A smoke run (\SmokeGames{} games with \texttt{\SmokeModel}, \$\SmokeCost) checked the pipeline: all
\SmokeReplayOK{} transcripts replay to their scores, \SmokeRefused{} of \SmokeCalls{} model calls were refused and
\SmokeNoBlock{} had no command, and both officer views parsed in all \SmokeOfficerParsed{} games. A calibration pilot
(one seed per task and level) checks that the control honest rate falls from D0 to D3 before the main runs
\torun{: calibration pilot}.

% ================= 6. Discussion and Limitations =================
\section{Discussion and Limitations}

\torun{: what the first finding means for agent deployments where the honest path is costly, and for defenders}

\subsection{Limitations}
\begin{itemize}
  \item \textbf{Prompted incentives.} The reward and the rule exist only in the prompt; nothing is at stake for the agents.
  \item \textbf{Cues.} The holder's note says the file ``was accidentally left'' in its workspace, which reads like a
        honeypot, and every brief says that previous-version answers are accepted, which tells non-holders that an older key
        exists. Both are constant across levels.
  \item \textbf{The honest path is pointed to.} Agents are told where the honest path is; levels vary its cost, not its
        discoverability. Agents who ignore the README pay a higher cost than the nominal level.
  \item \textbf{Scale.} \NSeeds{} seeds per cell and one sample per game; three models, one per safeguard and size profile;
        task differences bundle leak format, scoring and workload.
  \item \textbf{Officer.} One officer model, which shares a vendor with one agent model; the threshold rule undercounts
        partial or paraphrased use.
\end{itemize}

\subsection{Future Work}
Varying the collusive path's cost and the honest path's cost together; sanctions applied during the game; agents
instructed to hide; and a second officer from another vendor.

\section*{Limitations and Dual-Use / Ethical Considerations}
\textbf{What the result does and does not establish.} It measures whether a leak spreads in our testbed, with the models we
ran, as a function of the honest path's cost. It does not show that agents collude without a leak, that they can hide
collusion, or that an LLM officer works in general. \textbf{Dual use.} We report aggregate detection rates only, and publish
no catalogue of phrasings that evade the officer and no evasion prompts. All secrets are synthetic; there are no human
subjects.
