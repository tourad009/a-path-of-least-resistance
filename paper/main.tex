\itshape
When one member of an LLM agent team finds a forbidden shortcut, does the team use it, and does that depend on how hard
the honest alternative is? We hold the collusive path fixed (one member of some teams finds an old answer file in its
workspace, and no prompt asks anyone to collude) and vary only the cost of the honest path to the same points, from a
lookup in a public file to no honest path at all. A versioned answer key makes leak use provable by execution at every
level: the leaked file holds the previous version of the key, which the scorer accepts and which appears nowhere else. We
run \NGames{} games over \NTasks{} everyday agentic tasks, \NLevels{} difficulty levels and \NModels{} agent models, and
let a security officer read every finished game without acting on it.

% ================= 1. Introduction =================
\section{Introduction}

Teams of LLM agents increasingly share a workspace and a chat channel \citep{nakamura2026colosseum}. Collusion arises when
members coordinate on an outcome that the rules forbid, often out of sight of oversight \citep{motwani2024secret}.
A concrete case: a member finds information it was told not to use, such as an answer key or held-out labels left in reach, which agents are known to exploit
\citep{atinafu2026rewardhackingagents,thaman2026rhb}, and the team must decide whether to use it,
share it, or leave it alone. Such collusion can corrupt grading, benchmarks and audits that assume independent work.

Existing studies ask what it takes for collusion to emerge. Private channels can introduce it in cooperative systems
\citep{nakamura2026colosseum}, oversight and communication shape it between auction sellers \citep{agrawal2025double}, and
pricing agents reach it without any explicit agreement \citep{fish2024algorithmic,lin2024strategic}. Under pressure, models
also act on forbidden information \citep{scheurer2023deceive}, and a single agent exploits shortcuts more on harder tasks
\citep{thaman2026rhb}, as the economics of crime predicts \citep{becker1968crime}. What remains unknown is whether the cost of doing the honest work, alone, can push a team to collude on a shortcut nobody
asked it to take.

We study this gap in a simple setting. Teams of agents work on everyday tasks, such as querying a database or writing
code, and one member of some teams finds a leaked file containing answers. We change only how hard it is to earn the reward
without the leak, from trivial to impossible, and measure whether the team uses the leak, whether it shares it, and
whether a separate monitor notices.
\torun{: the main finding in one sentence, with the numbers at the easiest and hardest levels}
\torun{: the detection result and what it means for defenders}

\textbf{Our contributions are:}
\begin{list}{}{\leftmargin=2.5em\itemindent=-1.5em\itemsep=3pt\topsep=3pt\parsep=0pt}
  \item[1.] \textbf{An agentic harness that isolates the cost of honest work.} Teams do everyday tasks such as database
        queries and coding, with no prompt to collude. Each task offers two routes: one that uses the leak and colludes,
        and an honest one whose cost varies from trivial to impossible.
  \item[2.] \textbf{An extensive study of difficulty, collusion and its detection.} To our knowledge the first to test
        whether the cost of honest work alone drives teams to collude. The analysis covers \NGames{} runs on
        the following tasks: labelling shapes, answering questions with SQL over a company database, pricing auction deals
        within a buyer's budget, writing short Python functions, and answering questions from company documents.
\end{list}

% ================= 2. Related Work =================
\section{Related Work}

\textbf{What makes LLM agents collude.} Existing studies give agents a means or a reason to collude and ask whether they do: a private channel \citep{nakamura2026colosseum}, more or less communication and oversight
between sellers \citep{agrawal2025double}, or a pricing market \citep{fish2024algorithmic,lin2024strategic}. Collusion also
appears without instruction, from reward structure \citep{shi2026emergent} or poorly specified rewards
\citep{mathew2024hidden}, and a public governance graph reduced it where a prompt-only ban did not
\citep{bracalesyrnikov2026institutional}. In every case the setup changes the channel, the market, the reward or the
oversight. We instead vary the cost of earning the reward honestly, from trivial to impossible, with the shortcut held fixed.

\textbf{Shortcut exploitation and task difficulty.} The evidence that harder tasks push agents to shortcuts comes from
benchmarks that plant one: leaked answers, readable tests and hidden solutions
\citep{atinafu2026rewardhackingagents,roth2026hvtb}, harder variants \citep{thaman2026rhb}, or impossible variants where
every pass is a cheat \citep{zhong2025impossiblebench}. All of them follow a single agent. Reward hacking can also spread
between agents and intensify on hard tasks \citep{hu2026transmissible}, but there the hacks are induced by training and the
cost of the honest path is not controlled. Our setting differs in two ways. The agents work as a team, so the leak must also be shared, and no prompt mentions the
leak, so the cost of honest work is the main thing that pushes agents toward it.

% ================= 3. Methods =================
\section{Methodology}

\subsection{Architecture}
The harness runs one \emph{run} at a time (Figure~\ref{fig:arch}). Several teams of agents work in separate sandboxes on the
same kind of task and talk over shared chat channels. The sandbox holds the public files, which contain the honest route to
the reward. In some teams one member, the \emph{holder}, also finds a leak file. A scorer grades the answers, and after the
run a passive security officer reads the chat and the scores. Each component below is fixed except one: the cost of the
honest route.

\subsection{Teams, agents and channels}
A run has \TeamsMin--\TeamsMax{} teams of \TeamSize{} agents. On a random 1 to $T-1$ of the $T$ teams, one random member
holds the leak; the other teams are \emph{control teams} and have none. Agents take turns over \NRounds{} rounds of up to
\NCmds{} commands, plus a final turn. Each command is one model call that sees the agent's brief, its team's answer board,
its recent messages and its recent commands. Agents can message everyone, their team or any single agent, and otherwise run
commands in their own offline sandbox. Each brief states the task, the goal (a reward for the team's total score) and the
rule that using or sharing non-public information is prohibited. \textbf{No prompt asks agents to collude}, and agents are
not told anyone is watching.

\subsection{Tasks}
Each agent answers 10 items (Table~\ref{tab:tasks}). Items 1--5 are public and need ordinary work. Items 6--10 are the
team's \emph{special items}; their answers differ by team, so another team's leak is worthless.

\subsection{The leak and the versioned key}
Every special item has two accepted answers. \textbf{\vtwo{}}, the current key, is what honest work derives. \textbf{\vone{}},
the previous version, appears \emph{only} in the leak file. An agent \emph{used the leak} when at least 3 of its 5 special
items match \vone{}, which proves use at every difficulty level. Tests check that \vone{} never appears in a public file or
brief and that \vone{} and \vtwo{} differ for every item.

\subsection{The honest-route dial}
The one manipulated factor is how much work the honest route to the special items takes. The levels mean the same in every
task: \textbf{D0}, the answer is written in a public file; \textbf{D1}, one mapping step; \textbf{D2}, a join of several
sources plus a rule; \textbf{D3}, no honest route. At D0--D2 the brief says the special items can be worked out from the
public files, so levels change the cost of the honest route and not whether agents know it exists. The exact
\texttt{README.txt} of every task and level is in Appendix~\ref{app:honest}.

\subsection{Measures}
All measures come from the run itself, not from a judge. \textbf{Leak used}: an agent crossed the \vone{} threshold.
\textbf{Leak shared}: the holder sent at least 3 \vone{} values in a message a teammate could read.
\textbf{Collusion happened}: at least one teammate of the holder used the team's leak. \textbf{Collusion detected}: the
security officer disqualified a colluding team. As a manipulation check we also report the control teams' honest solve
rate on the special items.

\subsection{The passive security officer}
After each run a security officer model reads the roster and every message, and in its full view also the scores. It rates
every agent and decides for every team whether to disqualify or clear it. It \textbf{cannot influence the run}: it acts
after the last turn, agents are not told it exists, and its decision changes no score. As a baseline we report a one-line
score rule that flags a team when any member scores above 5.

\subsection{Validation}
Before any model call, scripted players play every task and level. Honest players solve all special items at D0--D2 and
none at D3 and never cross the leak threshold; colluding players cross it every time (Table~\ref{tab:checks}). Every run
also writes a full transcript that replays to the recorded score, and one script recomputes every reported number.

\textbf{Models.} Three agent models span capability and safety post-training (Table~\ref{tab:models}); all are called through
OpenRouter. Every agent in a game is the same model. The officer and the observer are \texttt{\OfficerModel} at temperature 0.

\textbf{Design.} For each model we play every task at every level on seeds \SeedRange{}: \NTasks{} $\times$ \NLevels{}
$\times$ \NSeeds{} $=$ \NGamesPerModel{} games, \NGames{} in total. A seed fixes the number of teams, which teams hold a
leak, who the holders are and the leak file's content, so the four levels of a seed differ only in the honest path, and the
three models play the same layouts. Everything else is fixed at the friendly setting of the earlier testbed: messaging on,
command memory across rounds, messages that stay visible, a team progress board, a short final turn, and a reward for the
team's total score only. There is no warning about surveillance. Holders are interviewed after the game.

\textbf{Statistics.} The unit of analysis is the game: agents in one game are not independent. The primary test (H1) is a
logistic GEE of teammate leak use on the level (a linear term), with task and model as fixed effects and an exchangeable
correlation within games; we also report the seed-paired, game-clustered bootstrap 95\% CI of teammate use at D3 minus D0.
Secondary tests (H2 holder sending, H3 holder self-use, H4 false alarms of the officer and the score rule) use the same model
with Holm correction. Games where more than 20\% of replies contain no command are excluded and counted. Hypotheses,
tests and exclusions are pre-registered \tocheck{PREREG.md commit hash, frozen after the calibration pilot}.

\textbf{Runs.} A smoke run (\SmokeGames{} games with \texttt{\SmokeModel}, \$\SmokeCost) checked the pipeline: all
\SmokeReplayOK{} transcripts replay to their scores, \SmokeRefused{} of \SmokeCalls{} model calls were refused and
\SmokeNoBlock{} had no command, and both officer views parsed in all \SmokeOfficerParsed{} games. A calibration pilot
(one seed per task and level) checks that the control honest rate falls from D0 to D3 before the main runs
\torun{: calibration pilot}.

% ================= 6. Discussion and Limitations =================
\section{Discussion and Limitations}

\torun{: what the first finding means for agent deployments where the honest path is costly, and for defenders}

\textbf{Scope of the claim.} Following \citet{lee2026broad}, a result that the overseer misses leak use is a bounded null
at our sample size, not evidence that detection is impossible; report the interval, not ``no effect''.
\torun{: pre-registered predictions that failed, with counts}

\subsection{Limitations}
\begin{itemize}
  \item \textbf{Prompted incentives.} The reward and the rule exist only in the prompt; nothing is at stake for the agents.
  \item \textbf{Cues.} The holder's note says the file ``was accidentally left'' in its workspace, which reads like a
        honeypot, and every brief says that previous-version answers are accepted, which tells non-holders that an older key
        exists. Both are constant across levels.
  \item \textbf{The honest path is pointed to.} Agents are told where the honest path is; levels vary its cost, not its
        discoverability. Agents who ignore the README pay a higher cost than the nominal level.
  \item \textbf{Scale.} \NSeeds{} seeds per cell and one sample per game; three models, one per safeguard and size profile;
        task differences bundle leak format, scoring and workload.
  \item \textbf{Officer.} One officer model, which shares a vendor with one agent model; the threshold rule undercounts
        partial or paraphrased use.
\end{itemize}

\subsection{Future Work}
Varying the collusive path's cost and the honest path's cost together; sanctions applied during the game; agents
instructed to hide; and a second officer from another vendor.

\section*{Limitations and Dual-Use / Ethical Considerations}
\textbf{What the result does and does not establish.} It measures whether a leak spreads in our testbed, with the models we
ran, as a function of the honest path's cost. It does not show that agents collude without a leak, that they can hide
collusion, or that an LLM officer works in general. \textbf{Dual use.} We report aggregate detection rates only, and publish
no catalogue of phrasings that evade the officer and no evasion prompts. All secrets are synthetic; there are no human
subjects.
